# SQL TRUNCATE: 데이터베이스 테이블의 빠른 삭제 방법

## 개요
SQL의 TRUNCATE 명령어는 데이터베이스 테이블에서 모든 행을 신속하게 삭제하는 기능을 제공합니다. TRUNCATE는 DELETE 명령어와 유사하지만, 데이터 삭제 속도와 로그 기록 측면에서 더 효율적입니다.

## 문서화

### 목적
TRUNCATE 명령어의 주된 목적은 테이블의 모든 데이터를 삭제하는 것입니다. 이 명령어는 테이블 구조는 유지하면서 데이터를 제거하며, 데이터 삭제 후에는 자동으로 해당 테이블의 모든 행이 초기화됩니다.

### 사용법
TRUNCATE 명령어는 다음과 같은 구문으로 사용합니다:

```sql
TRUNCATE TABLE 테이블명;
```

여기서 `테이블명`은 데이터를 삭제하고자 하는 테이블의 이름입니다. TRUNCATE는 모든 행을 삭제하지만, 테이블의 정의(스키마)는 그대로 유지합니다.

### 세부 사항
- TRUNCATE는 DELETE 명령어와 달리 WHERE 절을 지원하지 않습니다. 즉, 특정 조건에 맞는 행만 삭제할 수 없습니다.
- TRUNCATE 실행 후에는 삭제된 데이터를 복구할 수 없습니다. 따라서 사용 시 주의가 필요합니다.
- TRUNCATE는 데이터베이스 로그에 최소한의 정보를 기록하므로, 대량의 데이터를 삭제할 때 성능이 더 뛰어납니다.
- 외래 키 제약 조건이 있는 테이블에 대해서는 TRUNCATE를 사용할 수 없습니다. 이러한 경우 DELETE 명령어를 사용해야 합니다.

## 예제

1. 기본 TRUNCATE 사용 예:

```sql
TRUNCATE TABLE Employees;
```
위 명령어는 `Employees` 테이블의 모든 데이터를 삭제합니다.

2. TRUNCATE 후 데이터 확인:

```sql
SELECT * FROM Employees;
```
TRUNCATE 명령어 실행 후 이 쿼리의 결과는 빈 결과셋을 반환합니다.

## 설명
- TRUNCATE 명령어는 테이블을 재설정하는 데 유용하지만, 사용하기 전에 데이터 손실에 대한 충분한 이해가 필요합니다.
- TRUNCATE는 DELETE와 다르게, 단일 트랜잭션으로 처리되며, 롤백할 수 없습니다. 따라서 실행 전에 항상 백업을 고려해야 합니다.
- TRUNCATE는 테이블에 설정된 AUTO_INCREMENT 속성을 초기화하여, 다음 INSERT 시 첫 번째 행이 1부터 시작하게 됩니다. 이는 DELETE 후에는 유지됩니다.
