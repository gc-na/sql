# SQL GRANT 명령어: 권한 부여의 모든 것

## 개요
SQL의 GRANT 명령어는 데이터베이스 사용자 또는 역할에 특정 권한을 부여하는 데 사용됩니다. 이를 통해 데이터베이스에서의 작업을 제어하고 보안을 강화할 수 있습니다.

## 문서화

### 목적
GRANT 명령어는 데이터베이스 객체(테이블, 뷰, 프로시저 등)에 대한 사용자의 접근 권한을 설정합니다. 이를 통해 데이터베이스 관리자는 사용자가 수행할 수 있는 작업을 세분화하고, 데이터 무결성을 유지할 수 있습니다.

### 사용법
GRANT 명령어의 기본 구문은 다음과 같습니다:

```sql
GRANT 권한 목록 
ON 객체 
TO 사용자 또는 역할;
```

- **권한 목록**: 부여할 권한의 종류 (예: SELECT, INSERT, UPDATE, DELETE 등).
- **객체**: 권한을 부여할 데이터베이스 객체.
- **사용자 또는 역할**: 권한을 부여받을 사용자 계정 또는 역할.

### 세부 사항
- 권한은 데이터베이스 관리자(DBA) 또는 해당 객체의 소유자만 부여할 수 있습니다.
- GRANT는 여러 권한을 동시에 부여할 수 있으며, 쉼표로 구분하여 나열합니다.
- GRANT 명령어는 다른 사용자에게 권한을 부여할 수 있는 WITH GRANT OPTION을 추가하여, 해당 사용자도 다른 사용자에게 권한을 부여할 수 있게 할 수 있습니다.

## 예제

1. 특정 테이블에 대한 SELECT 권한 부여:

```sql
GRANT SELECT ON employees TO user1;
```

2. 여러 권한을 부여하는 예:

```sql
GRANT SELECT, INSERT, UPDATE ON employees TO user2;
```

3. WITH GRANT OPTION을 사용하여 다른 사용자에게 권한 부여:

```sql
GRANT SELECT ON employees TO user3 WITH GRANT OPTION;
```

## 설명
GRANT 명령어 사용 시 주의해야 할 몇 가지 사항이 있습니다:

- **권한 상속**: 사용자가 다른 사용자에게 권한을 부여할 수 있게 되면, 권한 관리가 복잡해질 수 있습니다. 따라서 신뢰할 수 있는 사용자에게만 WITH GRANT OPTION을 부여하는 것이 좋습니다.
- **권한 확인**: GRANT 명령어로 부여한 권한은 데이터베이스의 시스템 카탈로그나 정보 스키마에서 확인할 수 있습니다.
- **권한 철회**: 부여된 권한은 REVOKE 명령어를 사용하여 철회할 수 있습니다.

## 한 줄 요약
SQL의 GRANT 명령어는 사용자 또는 역할에 데이터베이스 객체에 대한 권한을 부여하여 데이터 접근과 관리를 제어하는 중요한 도구입니다.
