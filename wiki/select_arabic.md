# SELECT: استعلام SQL الأساسي لاسترجاع البيانات

## ملخص
أمر SELECT في SQL هو أداة قوية تُستخدم لاسترجاع البيانات من قاعدة البيانات. يُعتبر هذا الأمر أساسياً في عمليات تحليل البيانات وإدارتها، مما يجعله من أكثر الأوامر استخداماً في لغة SQL.

## الوثائق
### الغرض
يُستخدم أمر SELECT لاسترجاع البيانات من جداول قاعدة البيانات. يمكنك من خلاله تحديد الأعمدة التي ترغب في استرجاعها، كما يسمح بالفلترة، والترتيب، والتجميع، مما يوفر لك مرونة كبيرة في عرض البيانات.

### الاستخدام
يتم استخدام أمر SELECT بالشكل التالي:
```sql
SELECT column1, column2, ...
FROM table_name
WHERE condition;
```

- **column1, column2, ...**: الأعمدة التي تريد استرجاعها.
- **table_name**: اسم الجدول الذي يحتوي على البيانات.
- **condition**: شرط اختياري لتحديد السجلات المراد استرجاعها.

### التفاصيل
- يمكنك استخدام `*` لاسترجاع جميع الأعمدة من الجدول:
```sql
SELECT * FROM table_name;
```
- يمكن دمج SELECT مع عدة أوامر أخرى مثل `ORDER BY` و `GROUP BY` و `JOIN` لتحقيق نتائج أكثر تعقيداً.
- يمكن استخدام الدوال التجميعية مثل `COUNT()` و `SUM()` لتحليل البيانات.

## الأمثلة
### مثال 1: استرجاع جميع الأعمدة من جدول
```sql
SELECT * FROM employees;
```

### مثال 2: استرجاع أعمدة محددة
```sql
SELECT first_name, last_name FROM employees;
```

### مثال 3: استخدام WHERE لتصفية النتائج
```sql
SELECT * FROM employees WHERE department = 'Sales';
```

### مثال 4: ترتيب النتائج
```sql
SELECT * FROM employees ORDER BY last_name ASC;
```

### مثال 5: استخدام دالة تجميعية
```sql
SELECT COUNT(*) FROM employees WHERE department = 'Sales';
```

## الشرح
### المشكلات الشائعة
- **نسيان استخدام WHERE**: قد يؤدي استرجاع جميع الصفوف إلى الكثير من البيانات غير المرغوب فيها.
- **أخطاء في كتابة أسماء الأعمدة أو الجداول**: تأكد من مطابقة الأسماء مع تلك الموجودة في قاعدة البيانات.
- **استخدام دوال تجميعية بدون GROUP BY**: عند استخدام دوال مثل COUNT أو SUM، يجب أن تتأكد من وجود GROUP BY إذا كنت تجمع بيانات متعددة.

### ملاحظات إضافية
- تأكد من مراعاة أذونات الوصول عند استخدام SELECT، حيث قد لا تتمكن من استرجاع بيانات من الجداول التي ليس لديك حق الوصول إليها.
- يمكنك استخدام الكلمة الرئيسية DISTINCT لاسترجاع القيم الفريدة فقط:
```sql
SELECT DISTINCT department FROM employees;
```

## ملخص جملة واحدة
أمر SELECT في SQL هو الطريقة الأساسية لاسترجاع البيانات من الجداول، مع إمكانية تحديد الأعمدة، وتطبيق الشروط، والترتيب، والتحليل.
