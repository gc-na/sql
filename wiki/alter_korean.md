# SQL의 ALTER 명령어: 데이터베이스 객체 변경하기

## 개요
SQL의 ALTER 명령어는 데이터베이스 내의 테이블, 뷰, 인덱스 등 다양한 객체의 구조를 수정할 때 사용됩니다. 이 명령어를 통해 컬럼을 추가하거나 삭제하고, 데이터 타입을 변경하는 등 데이터베이스 설계를 유연하게 관리할 수 있습니다.

## 문서화

### 목적
ALTER 명령어는 기존 데이터베이스 객체의 속성을 변경하는 데 사용됩니다. 이는 데이터베이스의 설계를 개선하거나 비즈니스 요구 사항에 따라 조정할 때 매우 유용합니다.

### 사용법
ALTER 명령어는 여러 형태로 사용될 수 있으며, 가장 일반적인 사용법은 다음과 같습니다:

- **테이블 수정**: 테이블의 구조를 변경합니다.
- **컬럼 추가/삭제**: 테이블 내의 컬럼을 추가하거나 제거합니다.
- **데이터 타입 변경**: 기존 컬럼의 데이터 타입을 변경합니다.
- **제약조건 추가/삭제**: 테이블에 제약조건을 추가하거나 삭제합니다.

### 기본 문법
```sql
ALTER TABLE 테이블명
ADD 컬럼명 데이터타입;

ALTER TABLE 테이블명
DROP COLUMN 컬럼명;

ALTER TABLE 테이블명
ALTER COLUMN 컬럼명 데이터타입;
```

## 예제

1. **컬럼 추가**
   ```sql
   ALTER TABLE employees
   ADD birth_date DATE;
   ```

2. **컬럼 삭제**
   ```sql
   ALTER TABLE employees
   DROP COLUMN birth_date;
   ```

3. **데이터 타입 변경**
   ```sql
   ALTER TABLE employees
   ALTER COLUMN salary DECIMAL(10, 2);
   ```

4. **제약조건 추가**
   ```sql
   ALTER TABLE employees
   ADD CONSTRAINT chk_age CHECK (age >= 18);
   ```

## 설명
ALTER 명령어를 사용할 때 주의해야 할 몇 가지 사항이 있습니다:

- **데이터 손실**: 컬럼을 삭제하면 해당 컬럼의 모든 데이터가 손실됩니다. 삭제 전 데이터 백업을 권장합니다.
- **제약조건 충돌**: 제약조건을 추가할 때 기존 데이터가 제약조건을 위반할 경우 오류가 발생합니다.
- **트랜잭션**: ALTER 명령어는 대개 자동 커밋 방식으로 작동하므로, 변경 사항을 되돌리기 위해서는 트랜잭션을 명시적으로 관리해야 합니다.

## 한 줄 요약
ALTER 명령어는 SQL에서 테이블 및 데이터베이스 객체의 구조를 유연하게 변경할 수 있는 강력한 도구입니다.
