# SQL INSERT 명령어: 데이터베이스에 데이터 추가하기

## 개요
SQL의 INSERT 명령어는 데이터베이스의 테이블에 새로운 레코드를 추가할 때 사용됩니다. 이 명령어는 데이터베이스 관리 시스템(DBMS)에서 데이터를 삽입하는 기본적인 방법 중 하나입니다.

## 문서화

### 목적
INSERT 명령어는 특정 테이블에 새로운 행(row)을 추가하고, 이를 통해 데이터베이스의 정보를 업데이트하는 데 사용됩니다. 이 명령어를 통해 사용자는 데이터베이스에 필요한 정보를 손쉽게 입력할 수 있습니다.

### 사용법
INSERT 문법은 다음과 같습니다:

```sql
INSERT INTO 테이블명 (열1, 열2, 열3, ...)
VALUES (값1, 값2, 값3, ...);
```

- **테이블명**: 데이터를 삽입할 대상 테이블의 이름입니다.
- **열1, 열2, 열3, ...**: 값을 삽입할 열(column)의 이름입니다.
- **값1, 값2, 값3, ...**: 각 열에 삽입될 데이터의 실제 값입니다.

### 세부사항
- 열 이름을 명시할 경우, VALUES 절의 값은 열의 순서와 일치해야 합니다.
- 모든 열에 대한 값을 지정하지 않을 수도 있으며, 이 경우 NULL 값이 기본적으로 사용됩니다. 단, 열이 NULL을 허용해야 합니다.
- INSERT 명령어는 여러 레코드를 한 번에 삽입할 수도 있습니다:

```sql
INSERT INTO 테이블명 (열1, 열2)
VALUES (값1, 값2),
       (값3, 값4);
```

## 예제
1. 기본 INSERT 예제:

```sql
INSERT INTO Employees (FirstName, LastName, Age)
VALUES ('John', 'Doe', 30);
```

2. 여러 레코드 삽입:

```sql
INSERT INTO Employees (FirstName, LastName, Age)
VALUES ('Jane', 'Smith', 25),
       ('Emily', 'Johnson', 22);
```

## 설명
- **NULL 값**: 열에 NULL 값을 삽입할 때는 해당 열을 생략하거나 명시적으로 NULL을 입력할 수 있습니다.
- **제약조건**: 테이블에 설정된 제약조건(예: 기본 키, 외래 키) 때문에 삽입이 실패할 수 있습니다. 이 경우 에러 메시지를 통해 문제를 파악해야 합니다.
- **트랜잭션**: 데이터의 일관성을 유지하기 위해 INSERT를 트랜잭션 내에서 사용하는 것이 좋습니다. 이를 통해 여러 삽입 작업을 원자적으로 수행할 수 있습니다.

## 한 줄 요약
