# SQLのTRUNCATE: テーブルデータを迅速に削除する方法

## 概要
SQLの`TRUNCATE`コマンドは、データベースにおいてテーブルの全データを迅速に削除するために使用される命令です。`DELETE`文と異なり、`TRUNCATE`はテーブルを再構築することでデータを削除し、パフォーマンスが向上します。

## ドキュメンテーション
`TRUNCATE`コマンドの主な目的は、指定したテーブルのすべての行を削除することです。このコマンドは、次のような特徴を持っています。

- **高速性**: `TRUNCATE`は行を一つずつ削除するのではなく、ページ単位でデータを削除するため、パフォーマンスが大幅に向上します。
- **トランザクションログの最小化**: `TRUNCATE`は、削除された行の情報をトランザクションログに記録しないため、ログのサイズが小さく抑えられます。
- **リセット機能**: `TRUNCATE`を使用すると、テーブルのIDENTITY列がリセットされます。これにより、次回挿入される行のIDが1から始まります。
- **制約**: `TRUNCATE`は、外部キー制約が設定されているテーブルに対しては使用できません。

### 使用方法
```sql
TRUNCATE TABLE テーブル名;
```

## 例
以下は、`TRUNCATE`コマンドの基本的な使用例です。

### 例1: シンプルなテーブルのトランケート
```sql
TRUNCATE TABLE employees;
```
このコマンドは、`employees`テーブル内のすべての行を削除します。

### 例2: トランザクション内での使用
```sql
BEGIN TRANSACTION;
TRUNCATE TABLE orders;
COMMIT;
```
この例では、`orders`テーブルをトランザクション内でトランケートしますが、`TRUNCATE`はロールバックできないことに注意してください。

## 説明
`TRUNCATE`コマンドを使用する際の一般的な注意点や落とし穴は以下の通りです。

- **外部キー制約**: `TRUNCATE`は、外部キー制約が存在するテーブルには適用できません。このような場合は、まず制約を削除する必要があります。
- **ロールバック不可**: `TRUNCATE`はトランザクションの一部として使用することができますが、行の削除が即座に行われ、ロールバックはできません。データを誤って削除すると復元は難しいです。
- **パーミッション**: `TRUNCATE`を実行するには、テーブルを削除するのと同等の権限が必要です。

## 一行要約
SQLの`TRUNCATE`コマンドは、テーブルの全データを迅速に削除し、IDENTITY列をリセットする便利な方法です。
