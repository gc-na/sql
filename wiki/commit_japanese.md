# SQLのCOMMITコマンド：トランザクションの永続化を実現する

## 概要
SQLのCOMMITコマンドは、トランザクション内で実行されたすべての変更をデータベースに保存し、永続化するための重要な命令です。このコマンドを使用することで、データの整合性が保たれ、意図した変更が確実に適用されます。

## ドキュメンテーション
COMMITは、データベースのトランザクション処理において、すべての変更を確定させるためのコマンドです。トランザクションは、データベース内での一連の操作を一つの単位として扱います。これにより、途中でエラーが発生した場合でも、データの整合性を保つことが可能です。

### 使用目的
- **データの永続化**: COMMITコマンドを実行することで、トランザクション内のすべての変更がデータベースに保存されます。
- **整合性の確保**: 途中でエラーが発生した場合、ROLLBACKコマンドを使用することで、変更を元に戻すことができます。

### 使用方法
COMMITコマンドは、SQL文の最後に記述します。特に、INSERT、UPDATE、DELETEなどの操作を行った後に実行します。

```sql
BEGIN;

INSERT INTO users (name, age) VALUES ('山田太郎', 30);
UPDATE users SET age = 31 WHERE name = '山田太郎';
DELETE FROM users WHERE age < 20;

COMMIT;
```

上記の例では、ユーザー情報の追加、更新、削除を行った後、COMMITコマンドによってそれらの変更がデータベースに保存されます。

## 例
以下は、COMMITコマンドの基本的な使用例です。

### 例1: ユーザー追加
```sql
BEGIN;
INSERT INTO users (name, age) VALUES ('佐藤花子', 25);
COMMIT;
```

### 例2: ユーザー情報の更新
```sql
BEGIN;
UPDATE users SET age = 28 WHERE name = '佐藤花子';
COMMIT;
```

### 例3: 複数の操作のトランザクション
```sql
BEGIN;
INSERT INTO users (name, age) VALUES ('田中一郎', 22);
UPDATE users SET age = 29 WHERE name = '田中一郎';
DELETE FROM users WHERE name = '佐藤花子';
COMMIT;
```

## 説明
COMMITコマンドを使用する際の一般的な落とし穴や注意点として、以下の点が挙げられます。

- **トランザクションの範囲**: COMMITは、BEGINで開始したトランザクションのすべての変更を適用します。適用したくない変更がある場合は、必ずROLLBACKを使用して変更を元に戻してから、必要な変更のみをCOMMITするようにしましょう。
  
- **データベースのロック**: COMMITを実行することで、トランザクションが終了し、他のトランザクションがデータにアクセスできるようになります。ただし、トランザクションが長時間にわたると、他のユーザーによるデータアクセスが妨げられることがあります。

- **エラー処理**: COMMITの前にエラーが発生した場合は、ROLLBACKを使用してトランザクションを取り消すことが重要です。エラー処理を適切に行わないと、不完全なデータが保存される可能性があります。
