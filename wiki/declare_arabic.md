# DECLARE في SQL: تعريف وأمثلة

## ملخص
يعتبر الأمر DECLARE في SQL أداة مهمة لإعلان المتغيرات في الكود البرمجي، مما يساعد على تخزين القيم واستخدامها لاحقاً في العمليات المختلفة داخل قاعدة البيانات.

## الوثائق
### الغرض
يُستخدم الأمر DECLARE لتعريف متغيرات جديدة في SQL، مما يتيح للمطورين تخزين البيانات المؤقتة أثناء تنفيذ الاستعلامات أو الإجراءات المخزنة. يُعتبر هذا الأمر جزءًا من لغات البرمجة الخاصة بقواعد البيانات مثل T-SQL (SQL Server) وPL/pgSQL (PostgreSQL).

### الاستخدام
يتم استخدام DECLARE في سياقات متعددة، مثل الإجراءات المخزنة أو الاستعلامات المعقدة. صيغة الاستخدام الأساسية هي كما يلي:

```sql
DECLARE @اسم_المتغير نوع_البيانات;
```

### التفاصيل
- **اسم المتغير**: يجب أن يبدأ بحرف، ويمكن أن يحتوي على حروف وأرقام ورموز مثل (_) ولكن لا يمكن أن يحتوي على فراغات.
- **نوع البيانات**: يحدد نوع القيمة التي يمكن تخزينها في المتغير (مثل INT, VARCHAR, DATE، إلخ).
- يمكن استخدام المتغيرات المُعلنة في استعلامات SQL المختلفة مثل SELECT وUPDATE وINSERT.

## أمثلة
### مثال 1: إعلان متغير نصي
```sql
DECLARE @اسم NVARCHAR(50);
SET @اسم = 'أحمد';
SELECT @اسم AS 'اسم المستخدم';
```

### مثال 2: إعلان متغير عددي
```sql
DECLARE @عدد INT;
SET @عدد = 10;
SELECT @عدد * 2 AS 'العدد المضاعف';
```

### مثال 3: استخدام المتغير في إجراء مخزن
```sql
CREATE PROCEDURE حساب_المجموع
    @عدد1 INT,
    @عدد2 INT,
    @مجموع INT OUTPUT
AS
BEGIN
    SET @مجموع = @عدد1 + @عدد2;
END
```

## الشرح
### الفخاخ الشائعة
- **عدم تحديد نوع البيانات بشكل صحيح**: تأكد من تحديد نوع البيانات الصحيح للمتغير، حيث أن استخدام نوع خاطئ قد يؤدي إلى أخطاء أثناء المعالجة.
- **عدم تهيئة المتغيرات**: من المهم تهيئة المتغيرات قبل استخدامها، حيث قد تؤدي القيم غير المعروفة إلى نتائج غير متوقعة.
- **نطاق المتغيرات**: يجب أن تكون على دراية بنطاق المتغيرات المعلنة، حيث تكون المتغيرات محصورة في الإجراء أو الكتلة التي تم الإعلان عنها فيها.

## ملخص بجملة واحدة
الأمر DECLARE في SQL هو أداة قوية لإعلان المتغيرات، مما يسمح بتخزين واستخدام البيانات بشكل فعال في العمليات البرمجية.
