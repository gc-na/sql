# SQL INSERT 語句：數據庫數據插入的關鍵命令

## 簡介
SQL 中的 INSERT 語句用於向數據庫表中插入新數據行。這是一個基本的數據操作，對於任何數據庫應用程序來說都是至關重要的。

## 文檔
INSERT 語句的主要目的是將新的記錄添加到表中。這個命令的基本語法如下：

```sql
INSERT INTO 表名 (欄位1, 欄位2, …)
VALUES (值1, 值2, …);
```

### 使用方法
- **表名**：要插入數據的目標表的名稱。
- **欄位**：指定要插入的列，這些列必須存在於目標表中。
- **值**：對應於每個指定欄位的實際數據。

### 詳細說明
INSERT 語句可以有多種變體，包括：
1. **單行插入**：如上所示，插入一行新數據。
2. **多行插入**：可以在一次執行中插入多個新行：
   ```sql
   INSERT INTO 表名 (欄位1, 欄位2)
   VALUES (值1, 值2),
          (值3, 值4),
          (值5, 值6);
   ```
3. **從其他表插入**：也可以從另一個表中選擇數據插入：
   ```sql
   INSERT INTO 目標表 (欄位1, 欄位2)
   SELECT 欄位1, 欄位2 FROM 源表 WHERE 條件;
   ```

## 示例
以下是一些基本示例：

1. 單行插入：
   ```sql
   INSERT INTO 員工 (姓名, 年齡, 職位) 
   VALUES ('張三', 30, '工程師');
   ```

2. 多行插入：
   ```sql
   INSERT INTO 員工 (姓名, 年齡, 職位) 
   VALUES ('李四', 25, '設計師'),
          ('王五', 28, '產品經理');
   ```

3. 從其他表插入：
   ```sql
   INSERT INTO 員工 (姓名, 年齡, 職位)
   SELECT 姓名, 年齡, 職位 FROM 申請者 WHERE 狀態 = '通過';
   ```

## 解釋
使用 INSERT 語句時需要注意以下幾點：
- **數據類型**：插入的值必須與相應欄位的數據類型匹配。
- **非空約束**：如果欄位設置了非空約束，則必須提供相應的值。
- **主鍵約束**：如果某個欄位是主鍵，插入的值必須唯一，否則會報錯。
- **SQL注入**：在使用變量或用戶輸入時，應使用參數化查詢以防止SQL注入攻擊。

## 總結
INSERT 語句是 SQL 中用來插入數據的基本命令，對於數據的管理和操作至關重要。
