# تعديل (ALTER) في SQL: الأمر الأساسي لتغيير بنية الجداول

## الملخص
أمر "ALTER" في SQL هو أمر يستخدم لتغيير أو تعديل البنية الهيكلية لجداول البيانات، بما في ذلك إضافة أعمدة جديدة، تعديل أعمدة موجودة، أو حذف أعمدة.

## الوثائق
### الغرض
يستخدم أمر "ALTER" لتعديل بنية الجداول في قواعد البيانات. يمكن استخدامه لإجراء تغييرات متنوعة على الجداول، مثل إضافة أعمدة جديدة، تعديل أنواع بيانات الأعمدة، تغيير قيود البيانات، أو حتى حذف الأعمدة.

### الاستخدام
يمكن استخدام أمر "ALTER" بعدة طرق، حسب نوع التعديل المطلوب. الأشكال الأساسية لاستخدامه هي:

1. **إضافة عمود جديد:**
   ```sql
   ALTER TABLE table_name ADD column_name data_type;
   ```

2. **تعديل عمود موجود:**
   ```sql
   ALTER TABLE table_name MODIFY column_name new_data_type;
   ```

3. **حذف عمود:**
   ```sql
   ALTER TABLE table_name DROP COLUMN column_name;
   ```

4. **تغيير اسم جدول:**
   ```sql
   ALTER TABLE old_table_name RENAME TO new_table_name;
   ```

### التفاصيل
يمكن أن يتضمن أمر "ALTER" أيضًا تغيير قيود البيانات مثل الفهارس أو المفاتيح الأساسية. يجب أن يتم تنفيذ هذه الأوامر بحذر لأن التغييرات قد تؤثر على البيانات الموجودة.

## الأمثلة
### إضافة عمود جديد
```sql
ALTER TABLE employees ADD birth_date DATE;
```

### تعديل عمود موجود
```sql
ALTER TABLE employees MODIFY birth_date DATETIME;
```

### حذف عمود
```sql
ALTER TABLE employees DROP COLUMN birth_date;
```

### تغيير اسم جدول
```sql
ALTER TABLE employees RENAME TO staff;
```

## الشرح
- **الغفلات الشائعة:** أحد الأخطاء الشائعة هو محاولة حذف عمود يحتوي على بيانات مرتبطة أو قيود. يجب التأكد من عدم وجود اعتماديات على العمود قبل حذفه.
- **ملاحظات إضافية:** بعض أنظمة إدارة قواعد البيانات قد تتطلب إغلاق الجداول أو إعادة تشغيل الخدمة لتطبيق التغييرات.

## ملخص بمقدار جملة واحدة
أمر "ALTER" في SQL هو أداة قوية لتعديل بنية الجداول، مما يسمح بإجراء تغييرات مرنة على قاعدة البيانات حسب الحاجة.
