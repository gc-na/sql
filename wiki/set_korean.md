# SQL에서 SET 명령어에 대한 상세 가이드

## 개요
SQL의 SET 명령어는 데이터베이스 내에서 변수의 값을 설정하거나 특정 설정을 변경할 때 사용됩니다. 이는 주로 세션 변수, 전역 변수, 또는 특정 SQL 문장의 실행 환경을 조정하는 데 유용합니다.

## 문서화
SET 명령어는 SQL에서 두 가지 주요 용도로 사용됩니다. 첫 번째는 세션 변수의 값을 설정하는 것이고, 두 번째는 SQL 명령어의 실행 환경을 조정하는 것입니다. 

### 사용 목적
- **세션 변수 설정**: 사용자가 세션 동안 사용할 변수를 정의합니다.
- **환경 설정 변경**: SQL 명령어의 실행에 영향을 미치는 설정을 변경할 수 있습니다.

### 사용법
SET 명령어는 다음과 같은 구문을 따릅니다:

```sql
SET variable_name = value;
```

또는 환경 설정을 변경할 때는 다음과 같은 구문을 사용할 수 있습니다:

```sql
SET SESSION variable_name = value;
SET GLOBAL variable_name = value;
```

## 예제
1. 세션 변수를 설정하는 예제:
   ```sql
   SET @my_variable = 10;
   SELECT @my_variable; -- 결과: 10
   ```

2. SQL 모드 설정 변경 예제:
   ```sql
   SET SESSION sql_mode = 'STRICT_TRANS_TABLES';
   ```

3. 전역 변수를 설정하는 예제:
   ```sql
   SET GLOBAL max_connections = 200;
   ```

## 설명
SET 명령어를 사용할 때 주의해야 할 몇 가지 사항이 있습니다:

- **세션 vs 전역 변수**: 세션 변수는 현재 세션에만 영향을 미치며, 전역 변수는 모든 세션에 영향을 미칩니다. 전역 변수를 변경할 때는 권한이 필요할 수 있습니다.
- **변수 이름 규칙**: 변수 이름은 사용자 정의 변수와 시스템 변수를 구분하기 위해 '@' 기호로 시작해야 합니다.
- **SQL 모드**: SQL 모드를 변경할 때는 주의가 필요합니다. 잘못된 설정은 쿼리 실행에 부정적인 영향을 미칠 수 있습니다.

## 한 줄 요약
SQL의 SET 명령어는 변수 값을 설정하거나 SQL 실행 환경을 조정하는 데 사용됩니다.
