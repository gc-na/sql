# الكود END في SQL: كل ما تحتاج لمعرفته

## الملخص
كود "END" في SQL هو جزء حيوي من بناء الجمل الشرطية والحلقات، حيث يُستخدم لإنهاء الشروط أو الحلقات في استعلامات SQL.

## الوثائق
### الغرض
يستخدم الكود "END" في SQL للإشارة إلى نهاية جملة شرطية مثل "CASE" أو "IF" أو لإنهاء حلقات مثل "LOOP". يُعتبر جزءًا أساسيًا في تنظيم الشيفرة وجعلها قابلة للفهم.

### الاستخدام
يمكن استخدام "END" في عدة سياقات:
1. **في جمل CASE**: حيث يُستخدم لتحديد نهاية التعبير الشرطي.
2. **في جمل IF**: يشير إلى نهاية الشرط.
3. **في الحلقات**: يُستخدم لإنهاء حلقة معينة.

### التفاصيل
- في جمل **CASE**:
  ```sql
  SELECT 
      name,
      CASE 
          WHEN score >= 90 THEN 'A'
          WHEN score >= 80 THEN 'B'
          ELSE 'C'
      END AS grade
  FROM students;
  ```
  في المثال السابق، يتم استخدام "END" لتحديد نهاية التعبير الشرطي.

- في جمل **IF**:
  ```sql
  IF condition THEN
      -- بعض التعليمات
  END IF;
  ```
  هنا تُستخدم "END IF" للإشارة إلى نهاية جملة IF.

- في الحلقات:
  ```sql
  LOOP
      -- بعض التعليمات
  END LOOP;
  ```

## أمثلة
### مثال على جملة CASE
```sql
SELECT 
    product_name,
    CASE 
        WHEN stock > 50 THEN 'متوفر'
        WHEN stock = 0 THEN 'غير متوفر'
        ELSE 'قليل'
    END AS availability
FROM products;
```

### مثال على جملة IF
```sql
IF (salary > 5000) THEN
    UPDATE employees SET status = 'متميز';
END IF;
```

### مثال على حلقة
```sql
DECLARE 
    counter INT DEFAULT 0;
BEGIN
    LOOP
        EXIT WHEN counter >= 10;
        counter := counter + 1;
    END LOOP;
END;
```

## الشرح
### الأخطاء الشائعة
- **عدم استخدام "END" بشكل صحيح**: قد يؤدي ذلك إلى أخطاء في بناء الجملة، لذا تأكد من وضع "END" في المكان الصحيح.
- **عدم التوازن بين BEGIN و END**: تأكد من أن كل جملة تبدأ بـ "BEGIN" تنتهي بـ "END" لتجنب الأخطاء.

### ملاحظات إضافية
- في SQL، يُعتبر استخدام "END" أمرًا ضروريًا لفهم الشيفرة، لذا يجب الحرص على استخدامه بشكل جيد.

## ملخص بجملة واحدة
كود "END" في SQL هو عنصر أساسي لإنهاء الجمل الشرطية والحلقات، مما يساعد على تنظيم الشيفرة وجعلها أكثر وضوحًا.
