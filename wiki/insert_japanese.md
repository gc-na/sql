# SQLのINSERT文: データベースにデータを挿入する方法

## 概要
SQLのINSERT文は、データベースのテーブルに新しいレコードを追加するための基本的なコマンドです。このコマンドは、データベースのデータを管理する上で不可欠な機能であり、効率的なデータ操作を可能にします。

## ドキュメンテーション
### 目的
INSERT文は、データベース内のテーブルに新しい行を追加するために使用されます。このコマンドは、特定のカラムに対して値を指定し、テーブルの構造に従ってデータを挿入します。

### 使用法
基本的なINSERT文の構文は以下の通りです：

```sql
INSERT INTO テーブル名 (カラム1, カラム2, カラム3, ...)
VALUES (値1, 値2, 値3, ...);
```

#### 詳細
- **テーブル名**: データを挿入する対象のテーブルの名前。
- **カラム**: 挿入するデータの対象となるカラム名をカンマ区切りで指定。
- **値**: 挿入するデータの値をカンマ区切りで指定。

なお、カラムリストを省略することも可能ですが、その場合は全てのカラムに対して値を指定する必要があります。

## 例
1. 単純なINSERT文の例：

```sql
INSERT INTO users (username, email) 
VALUES ('john_doe', 'john@example.com');
```

2. 複数行のINSERT文の例：

```sql
INSERT INTO products (product_name, price) 
VALUES ('ペン', 100), ('ノート', 200);
```

3. カラムの指定を省略したINSERT文の例：

```sql
INSERT INTO orders 
VALUES (1, '2023-10-01', 500);
```

## 説明
INSERT文を使用する際にはいくつかの注意点があります。

- **データ型の一致**: 挿入する値は、テーブルで定義されたカラムのデータ型と一致する必要があります。例えば、整数型のカラムに文字列を挿入しようとするとエラーになります。
- **NULL制約の理解**: NULLを許可しないカラムに対して値を指定しない場合、エラーが発生します。必要なカラムには必ず値を提供することが重要です。
- **重複エラー**: 一意性制約が設定されているカラムに対して重複する値を挿入しようとすると、エラーが発生します。
