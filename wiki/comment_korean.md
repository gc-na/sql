# SQL에서의 COMMENT: 주석 추가하기

## 개요
SQL에서의 `COMMENT` 명령어는 데이터베이스 객체에 대한 주석을 추가하여, 해당 객체의 목적이나 사용 방법을 설명하는 데 사용됩니다. 이는 데이터베이스의 가독성을 높이고, 다른 사용자들이 이해하기 쉽게 도와줍니다.

## 문서화

### 목적
`COMMENT` 명령어는 테이블, 열, 뷰 및 기타 데이터베이스 객체에 대한 설명을 추가하는 데 사용됩니다. 이를 통해 데이터베이스 설계자 및 사용자들이 객체의 역할과 중요성을 쉽게 이해할 수 있도록 합니다.

### 사용법
`COMMENT` 명령어는 다음과 같은 구문으로 사용됩니다:

```sql
COMMENT ON [객체 유형] [객체 이름] IS '설명';
```

여기서 `객체 유형`은 테이블, 열, 뷰 등이며, `객체 이름`은 해당 객체의 이름, `설명`은 추가할 주석 내용입니다.

### 세부 사항
- `COMMENT` 명령어는 데이터베이스 관리 시스템(DBMS)의 종류에 따라 약간의 차이가 있을 수 있습니다.
- 주석은 주로 데이터베이스의 메타데이터에 저장되며, SQL 쿼리를 통해 조회할 수 있습니다.
- 주석을 추가하고자 하는 객체가 존재해야 하며, 객체에 대한 적절한 권한이 있어야 합니다.

## 예제

### 테이블에 주석 추가하기
```sql
COMMENT ON TABLE employees IS '직원 정보를 저장하는 테이블';
```

### 열에 주석 추가하기
```sql
COMMENT ON COLUMN employees.salary IS '직원의 연봉';
```

### 뷰에 주석 추가하기
```sql
COMMENT ON VIEW employee_view IS '직원 정보를 요약하여 보여주는 뷰';
```

## 설명
- `COMMENT` 명령어를 사용할 때, 주석 내용은 단일 인용부호로 감싸야 합니다. 이 부분을 잊으면 구문 오류가 발생할 수 있습니다.
- 주석을 추가한 후에는 데이터베이스 관리 도구나 SQL 쿼리를 통해 주석을 조회할 수 있으며, 이를 통해 데이터베이스 구조를 이해하는 데 도움이 됩니다.
- 주석은 데이터베이스 객체의 삭제나 수정 시 자동으로 삭제되지 않으며, 별도로 관리해야 합니다.

## 한 줄 요약
SQL의 `COMMENT` 명령어는 데이터베이스 객체에 대한 설명을 추가하여, 가독성과 이해도를 높이는 데 도움을 줍니다.
