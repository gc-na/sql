# SQL SELECT 문: 데이터 조회의 기초

## 개요
SQL의 SELECT 문은 데이터베이스에서 데이터를 조회하는 데 사용되는 가장 기본적이고 중요한 명령어입니다. 이를 통해 사용자는 특정 조건에 맞는 데이터를 선택하고, 필요한 형태로 결과를 반환받을 수 있습니다.

## 문서화

### 목적
SELECT 문은 데이터베이스 테이블에서 데이터를 검색하고 이를 다양한 형식으로 필터링하거나 정렬하는 기능을 제공합니다. 이를 통해 사용자는 원하는 정보를 효율적으로 얻을 수 있습니다.

### 사용법
SELECT 문은 다음과 같은 기본 구문을 가집니다:

```sql
SELECT 열1, 열2, ...
FROM 테이블명
WHERE 조건
ORDER BY 열
LIMIT 수량;
```

- **열1, 열2, ...**: 선택할 데이터의 열을 지정합니다. 모든 열을 선택하려면 `*`를 사용할 수 있습니다.
- **테이블명**: 데이터를 조회할 테이블의 이름을 지정합니다.
- **조건**: 검색할 데이터의 조건을 정의합니다. 이 부분은 선택 사항입니다.
- **ORDER BY 열**: 결과를 정렬할 열을 지정합니다.
- **LIMIT 수량**: 반환할 데이터의 수를 제한합니다.

## 예시
1. 특정 열 선택하기:
   ```sql
   SELECT 이름, 나이
   FROM 사용자;
   ```

2. 모든 열 선택하기:
   ```sql
   SELECT *
   FROM 주문;
   ```

3. 조건을 포함한 조회:
   ```sql
   SELECT 제품명, 가격
   FROM 제품
   WHERE 가격 > 10000;
   ```

4. 정렬하기:
   ```sql
   SELECT 이름, 나이
   FROM 사용자
   ORDER BY 나이 DESC;
   ```

5. 제한된 결과 반환하기:
   ```sql
   SELECT *
   FROM 주문
   LIMIT 5;
   ```

## 설명
SELECT 문 사용 시 주의해야 할 몇 가지 사항이 있습니다:

- **열 중복**: SELECT 문에서 동일한 열을 여러 번 선택하면 중복된 데이터가 반환될 수 있습니다.
- **NULL 값 처리**: 데이터베이스에 NULL 값이 포함된 열을 선택할 경우, 결과에 NULL이 포함될 수 있습니다. 이를 고려하여 쿼리를 작성해야 합니다.
- **대소문자 구분**: SQL은 대소문자를 구분하지 않지만, 데이터베이스 설정에 따라 다를 수 있으므로 주의가 필요합니다.
- **성능**: 대량의 데이터를 조회할 경우 성능 저하가 발생할 수 있습니다. WHERE 절을 사용하여 필요한 데이터만 조회하는 것이 좋습니다.
