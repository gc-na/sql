# إدخال البيانات في SQL: استخدام الأمر INSERT

## ملخص
يُستخدم الأمر INSERT في SQL لإدخال بيانات جديدة في جداول قاعدة البيانات. يعد هذا الأمر أساسيًا للتفاعل مع قواعد البيانات، حيث يتيح للمستخدمين إضافة سجلات جديدة بسهولة.

## الوثائق
### الغرض
يهدف الأمر INSERT إلى إضافة صفوف جديدة إلى جدول موجود في قاعدة البيانات. يمكن استخدامه لإدخال بيانات فردية أو متعددة في آن واحد.

### الاستخدام
يتم تنفيذ الأمر INSERT مع تحديد اسم الجدول الذي سيتم إدخال البيانات فيه، بالإضافة إلى القيم المراد إضافتها. يمكن أن يتم ذلك بعدة طرق، منها إدخال كل القيم أو تحديد أعمدة معينة.

### الصيغة الأساسية
```sql
INSERT INTO اسم_الجدول (اسم_العمود1, اسم_العمود2, ...)
VALUES (القيمة1, القيمة2, ...);
```

### إدخال بيانات متعددة
```sql
INSERT INTO اسم_الجدول (اسم_العمود1, اسم_العمود2, ...)
VALUES 
    (القيمة1, القيمة2, ...),
    (القيمة3, القيمة4, ...);
```

## أمثلة
### مثال 1: إدخال سجل جديد
```sql
INSERT INTO الموظفين (الاسم, العمر, الوظيفة)
VALUES ('أحمد', 30, 'مهندس');
```

### مثال 2: إدخال سجلات متعددة
```sql
INSERT INTO الموظفين (الاسم, العمر, الوظيفة)
VALUES 
    ('فاطمة', 25, 'مصممة'),
    ('سالم', 28, 'مطور');
```

### مثال 3: إدخال بيانات مع تحديد أعمدة معينة
```sql
INSERT INTO الموظفين (الاسم, الوظيفة)
VALUES ('علي', 'مدير');
```

## الشرح
### الأخطاء الشائعة
1. **عدم تطابق البيانات**: يجب أن تتطابق أنواع البيانات المدخلة مع أنواع الأعمدة المحددة. على سبيل المثال، لا يمكن إدخال نص في عمود مخصص للأرقام.
2. **فقدان القيم**: إذا تم تحديد أعمدة معينة، يجب التأكد من توفير القيم لجميع الأعمدة غير القابلة للنول.
3. **التكرار**: في حالة وجود قيود فريدة، مثل مفاتيح رئيسية، قد يؤدي إدخال قيم مكررة إلى حدوث خطأ.

### ملاحظات إضافية
- يمكن استخدام الأمر INSERT في عمليات الإدخال من استعلامات SELECT.
- من المهم مراعاة الأذونات المطلوبة لإجراء عمليات الإدخال في الجداول.

## ملخص جملة واحدة
الأمر INSERT في SQL يُستخدم لإدخال سجلات جديدة في الجداول، مما يسهل إدارة البيانات داخل قاعدة البيانات.
