# ROLLBACK: SQLにおけるトランザクションの取り消し

## 概要
SQLの「ROLLBACK」コマンドは、トランザクション内で行った変更を取り消すために使用されます。これは、データの整合性を維持し、エラーが発生した場合に以前の状態に戻すための重要な機能です。

## ドキュメンテーション
### 目的
「ROLLBACK」コマンドは、トランザクションが開始されてから行われたすべての変更を元に戻すために使用されます。これにより、データベースの状態を安全に保ちながら、複数の操作をまとめて管理することができます。

### 使用法
一般的な使用法は以下の通りです。
1. トランザクションを開始するために「BEGIN TRANSACTION」または「START TRANSACTION」を使用します。
2. データの挿入、更新、削除などの操作を行います。
3. エラーが発生した場合や、操作を取り消したい場合に「ROLLBACK」を実行します。

### 詳細
- **トランザクションの概念**: トランザクションは、データベースに対する一連の操作を意味し、すべての操作が成功するか、すべてが失敗するかのいずれかです。
- **整合性の維持**: ROLLBACKを使用することで、データベースの状態を以前の正しい状態に戻し、データの整合性を保つことができます。

## 例
以下は、「ROLLBACK」の基本的な使用例です。

```sql
BEGIN TRANSACTION;

INSERT INTO users (name, age) VALUES ('Alice', 30);
INSERT INTO users (name, age) VALUES ('Bob', 25);

-- エラーが発生した場合、または取り消したい場合
ROLLBACK;
```

この例では、AliceとBobのユーザー情報が追加されますが、ROLLBACKを実行することで、これらの変更はすべて取り消されます。

## 説明
- **一般的な落とし穴**: ROLLBACKを使用する際に注意が必要なのは、トランザクションが開始されていない状態で実行するとエラーが発生することです。
- **自動コミット**: 一部のデータベースシステムでは、デフォルトで自動コミットモードが有効になっており、明示的にトランザクションを開始しないとROLLBACKが機能しないことがあります。
- **必要な権限**: ROLLBACKを実行するには、適切な権限が必要です。アクセス権がない場合、コマンドは失敗します。
