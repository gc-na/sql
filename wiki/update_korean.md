# SQL UPDATE 명령어: 데이터베이스 레코드 수정하기

## 개요
SQL UPDATE 명령어는 데이터베이스 내의 기존 레코드를 수정하는 데 사용됩니다. 특정 조건을 만족하는 레코드의 한 또는 여러 개의 필드를 업데이트할 수 있으며, 이를 통해 데이터의 정확성과 최신성을 유지할 수 있습니다.

## 문서화
### 목적
UPDATE 명령어는 데이터베이스에서 특정 조건에 맞는 레코드의 내용을 수정하는 데 사용됩니다. 이 명령어를 통해 사용자는 데이터베이스의 정보를 실시간으로 변경할 수 있습니다.

### 사용법
UPDATE 명령어의 기본 구문은 다음과 같습니다:

```sql
UPDATE 테이블명
SET 열1 = 값1, 열2 = 값2, ...
WHERE 조건;
```

- **테이블명**: 수정할 데이터가 있는 테이블의 이름입니다.
- **열1, 열2, ...**: 수정할 열의 이름입니다.
- **값1, 값2, ...**: 각 열에 설정할 새로운 값입니다.
- **조건**: 수정할 레코드를 선택하는 조건입니다 (선택 사항). 조건을 지정하지 않으면 모든 레코드가 수정됩니다.

### 세부사항
- WHERE 절을 사용하지 않으면 테이블의 모든 레코드가 수정되므로 주의가 필요합니다.
- 여러 열을 동시에 수정할 수 있으며, 각 열은 쉼표로 구분합니다.
- 서브쿼리나 조인(Join)을 활용하여 더 복잡한 업데이트도 가능합니다.

## 예제
1. 특정 사용자의 이메일 주소 수정하기:
```sql
UPDATE 사용자
SET 이메일 = 'newemail@example.com'
WHERE 사용자ID = 1;
```

2. 모든 제품의 가격을 10% 인상하기:
```sql
UPDATE 제품
SET 가격 = 가격 * 1.10;
```

3. 특정 조건에 맞는 주문의 상태 변경하기:
```sql
UPDATE 주문
SET 상태 = '배송 중'
WHERE 주문ID = 150 AND 상태 = '처리 중';
```

## 설명
- **일관성 유지**: UPDATE 명령어를 사용할 때, 트랜잭션을 활용하여 데이터의 일관성을 유지하는 것이 중요합니다. 데이터베이스가 여러 사용자에 의해 동시에 수정되는 경우, 트랜잭션을 통해 데이터 충돌을 방지할 수 있습니다.
- **백업**: 대량의 레코드를 수정하기 전에 데이터베이스의 백업을 만드는 것이 좋습니다. 실수로 잘못된 데이터를 수정할 경우 복구가 필요할 수 있습니다.
- **성능 고려**: WHERE 절을 사용하는 경우, 인덱스를 활용하여 성능을 향상시킬 수 있습니다. 조건에 맞는 레코드가 많을 경우, 데이터베이스 성능에 영향을 줄 수 있습니다.

## 한 줄 요약
SQL UPDATE 명령어는 데이터베이스의 기존 레코드를 수정하여 데이터의 최신성을 유지하는 데 사용됩니다.
