# SQL DELETE 명령어: 데이터베이스에서 데이터 삭제하기

## 개요
SQL의 DELETE 명령어는 데이터베이스 테이블에서 특정 데이터를 삭제하는 데 사용됩니다. 이 명령어를 통해 사용자는 불필요한 데이터나 잘못된 데이터를 삭제할 수 있으며, 데이터베이스의 무결성을 유지하는 데 중요한 역할을 합니다.

## 문서화

### 목적
DELETE 명령어는 SQL 데이터베이스에서 하나 이상의 레코드를 삭제하는 데 사용됩니다. 이를 통해 사용자는 특정 조건에 맞는 데이터를 쉽게 제거할 수 있습니다.

### 사용법
DELETE 명령어의 기본 구문은 다음과 같습니다:

```sql
DELETE FROM 테이블명 WHERE 조건;
```

- **테이블명**: 삭제하려는 데이터가 포함된 테이블의 이름입니다.
- **조건**: 어떤 레코드를 삭제할지를 결정하는 조건식입니다. 이 부분이 생략되면 테이블의 모든 레코드가 삭제됩니다.

### 세부사항
- DELETE 명령어는 트랜잭션을 지원하며, 롤백이 가능합니다.
- WHERE 절을 사용하지 않으면 테이블의 모든 데이터가 삭제됩니다.
- DELETE 명령어는 FOREIGN KEY 제약 조건에 의해 영향을 받을 수 있습니다. 관련된 데이터가 있는 경우 삭제가 실패할 수 있습니다.

## 예제

### 기본 사용 예제
1. 특정 조건을 만족하는 데이터 삭제:
   ```sql
   DELETE FROM employees WHERE employee_id = 10;
   ```

2. 모든 데이터 삭제:
   ```sql
   DELETE FROM employees;
   ```

3. 여러 조건을 사용한 데이터 삭제:
   ```sql
   DELETE FROM employees WHERE department = 'Sales' AND hire_date < '2020-01-01';
   ```

## 설명
DELETE 명령어를 사용할 때 주의해야 할 몇 가지 사항이 있습니다:

- **WHERE 절의 중요성**: WHERE 절을 생략하면 모든 데이터가 삭제되므로, 실수로 데이터 손실을 방지하기 위해 항상 조건을 확인해야 합니다.
- **트랜잭션 관리**: 대량의 데이터를 삭제할 경우, 트랜잭션을 사용하여 변경 사항을 안전하게 관리하는 것이 좋습니다.
- **제약 조건**: DELETE 명령어는 제약 조건에 의해 실패할 수 있으므로, 관련된 데이터가 있는 경우 주의해야 합니다.

## 한 줄 요약
SQL DELETE 명령어는 특정 조건에 맞는 레코드를 데이터베이스에서 삭제하는 데 사용됩니다.
