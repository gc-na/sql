# SQL의 DECLARE 문: 변수 선언의 기초

## 개요
SQL의 DECLARE 문은 프로시저 또는 함수 내에서 변수를 선언하고 초기화하는 데 사용됩니다. 이 문은 데이터베이스 작업에서 동적 쿼리와 조건부 로직을 처리할 수 있는 유연성을 제공합니다.

## 문서화

### 목적
DECLARE 문은 SQL에서 로컬 변수를 선언하여 프로시저나 함수 내에서 사용할 수 있게 합니다. 이를 통해 개발자는 계산된 값을 저장하거나 쿼리의 결과를 임시적으로 보관할 수 있습니다.

### 사용법
DECLARE 문은 일반적으로 다음과 같은 형식으로 사용됩니다:

```sql
DECLARE 변수명 데이터타입 [DEFAULT 초기값];
```

- **변수명**: 선언할 변수의 이름입니다.
- **데이터타입**: 변수에 저장할 데이터의 유형을 지정합니다.
- **DEFAULT 초기값**: 변수의 초기값을 설정합니다. 선택 사항입니다.

### 세부 사항
- DECLARE 문은 트랜잭션 또는 프로시저 블록 내에서만 사용할 수 있습니다.
- 변수 이름은 대소문자를 구분하지 않으며, 일반적으로 명확하고 직관적인 이름을 사용하는 것이 좋습니다.
- 변수의 데이터 타입은 기본적으로 SQL에서 제공하는 타입(예: INT, VARCHAR, DATE 등)을 사용할 수 있습니다.

## 예제

### 기본 사용 예제

1. 정수형 변수 선언:

```sql
DECLARE @Count INT;
SET @Count = 10;
```

2. 문자열 변수 선언:

```sql
DECLARE @Name VARCHAR(50) DEFAULT '홍길동';
```

3. 날짜형 변수 선언:

```sql
DECLARE @Today DATE;
SET @Today = GETDATE();
```

4. 변수와 함께 SELECT 문 사용:

```sql
DECLARE @TotalSales DECIMAL(10, 2);
SELECT @TotalSales = SUM(SalesAmount) FROM SalesRecords;
```

## 설명
- **변수 스코프**: DECLARE로 선언된 변수는 해당 블록 내에서만 유효합니다. 블록을 벗어나면 변수는 더 이상 접근할 수 없습니다.
- **초기화 누락**: 변수를 선언만 하고 초기화하지 않으면, 해당 변수를 사용하는 쿼리에서 NULL 값이 발생할 수 있습니다. 반드시 초기값을 설정해주는 것이 좋습니다.
- **이름 중복**: 동일한 스코프 내에서 같은 이름의 변수를 여러 번 선언할 수 없습니다. 이는 오류를 발생시킬 수 있습니다.

## 한 줄 요약
DECLARE 문은 SQL에서 로컬 변수를 선언하고 초기화하여 데이터베이스 작업의 유연성을 높이는 데 사용됩니다.
