# SQL 中的 DELETE 指令：刪除資料的關鍵命令

## 簡介
DELETE 指令是 SQL 中用於從資料表中移除一或多條記錄的命令。這個功能對於資料管理至關重要，能夠幫助用戶清理不再需要的資料。

## 文件說明
DELETE 指令的主要目的是從資料庫的表中刪除特定的記錄。當你需要移除不再相關或錯誤的資料時，DELETE 是一個非常有效的工具。

### 使用方式
DELETE 指令的基本語法如下：

```sql
DELETE FROM 表名
WHERE 條件;
```

- **表名**：要刪除資料的資料表名稱。
- **條件**：指定哪些記錄將被刪除。若不使用 WHERE 條件，則會刪除表中的所有記錄。

### 注意事項
- 使用 DELETE 指令時，請務必小心，因為一旦資料被刪除，將無法恢復。
- 為了防止意外刪除，建議先使用 SELECT 查詢檢查將要刪除的資料。

## 範例
### 基本範例
1. 刪除特定條件的記錄：

```sql
DELETE FROM customers
WHERE customer_id = 5;
```

2. 刪除所有記錄：

```sql
DELETE FROM orders;
```

3. 使用複雜條件刪除記錄：

```sql
DELETE FROM products
WHERE price < 10 AND stock = 0;
```

## 解釋
在使用 DELETE 指令時，有一些常見的陷阱和注意事項：
- **刪除所有資料**：如果忘記加上 WHERE 條件，整個資料表的資料將被刪除，這通常是不可逆轉的。
- **資料完整性**：如果資料表中有外鍵約束，刪除操作可能會失敗，因為相關的資料仍然存在。
- **事務控制**：在執行刪除操作時，使用事務 (TRANSACTION) 來確保資料的安全性與一致性。

## 一句總結
SQL 中的 DELETE 指令用於有效地從資料表中刪除特定或所有資料記錄，必須謹慎使用以避免意外刪除。
